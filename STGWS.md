# exteraGram sTGWS

Сборка exteraGram со встроенным sTGWS: Telegram работает без VPN и без настроек прокси — как
пакет `tgws` на роутере, только внутри самого приложения.

- Пакет: `com.exteragram.stgws` (ставится рядом с обычным exteraGram/Telegram).
- Название: «exteraGram sTGWS».

## Как работает

При запуске приложение поднимает у себя на `127.0.0.1` маленький SOCKS5 (случайный порт,
случайные логин и пароль — другим приложениям на телефоне он недоступен) и сетевое ядро
Telegram ходит к дата-центрам через него. Дальше для каждого соединения:

1. по адресу определяется дата-центр (1–5, обычный или медийный; новые адреса берутся из
   `help.getConfig`);
2. если подбор показал, что этот ДЦ у оператора открыт, — соединение идёт напрямую; промолчал
   7 секунд — ДЦ считается закрытым, следующее соединение идёт через веб-сокет;
3. иначе поток MTProto заворачивается в веб-сокет `wss://kwsN.<домен>/apiws` к домену за
   Cloudflare. Провайдер видит обычный HTTPS к чужому домену.

Мост ничего не расшифровывает: шифрование MTProto сквозное между приложением и дата-центром.

Подбор (аналог `tgws pick`) идёт в фоне при запуске, при смене сети и раз в полчаса:
прямые пробы ко всем ДЦ, отсев пула доменов, затем карта «ДЦ → лучший домен». Проба — не
«соединилось ли», а настоящий ответ `resPQ` на `req_pq_multi`. Пул доменов — снимок из
[xyzmean/brb](https://gitlab.com/xyzmean/brb), при запуске подтягивается свежий список.

- Свой прокси в настройках Telegram главнее: если он включён, встроенный мост не используется.
- Системный VPN не мешает: сокеты моста идут туда же, куда шёл бы сам Telegram.
- Звонки идут по UDP мимо MTProto — через веб-сокет они не пойдут (ограничение способа).

Код: `TMessagesProj/src/main/java/com/exteragram/messenger/tgws/`.

## Сборка

Нужны Android SDK (platform 33, build-tools 33.0.1), NDK 21.4.7075529, CMake 3.10.2, JDK 17.

Файл `API_KEYS` в корне (в git не попадает):

```
APP_ID = 4
APP_HASH = "014b35b6184100b085b0d0572f9b5103"
MAPS_V2_API = none
SIGNING_KEY_PASSWORD = stgwspass
SIGNING_KEY_ALIAS = stgws
SIGNING_KEY_STORE_PASSWORD = stgwspass
```

`APP_ID`/`APP_HASH` — публичные ключи из исходников официального Telegram for Android; свои
можно получить на https://my.telegram.org. Ключ подписи — `TMessagesProj/config/stgws.jks`
(лежит в репозитории, чтобы новые сборки ставились поверх старых без потери входа).

```
./gradlew --no-configuration-cache assembleArm64Release
```

APK: `TMessagesProj/build/outputs/apk/arm64/release/`.

Закрытая часть exteraGram (`com/exteragram/messenger/boost`) в публичных исходниках
отсутствует — вместо неё заглушки; шифрование сообщений exteraGram в этой сборке отключено.
